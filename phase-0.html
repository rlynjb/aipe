0.1 Claude Code Mastery

Why This Track Exists

Applied AI is the outermost ring. It's not about building AI products — it's about using AI tools to build ANY product faster. Every hour invested here pays dividends across buffr, contrl, loopd, Twitch tools, and Notion projects. It's also the fastest path to freelance income: companies pay premium rates for devs who set up AI-augmented workflows.

Industry standard (March 2026): 95% use AI weekly. 46% name Claude Code as favourite. 70% use 2–4 tools. The .claude/ directory is the new project config standard.

Exercise 0A Set Up CLAUDE.md for buffr buffr ▶
  1. Run claude /init in the buffr repo root
  2. Add build commands: npm run build, npm run dev, npm test
  3. Add architecture: "Next.js 14, Netlify Functions, Netlify Blobs, LangChain.js"
  4. Add conventions: "TypeScript strict, no default exports, feature-first dirs"
  5. Add the 13 serverless functions + 5 chain names
  6. Commit to git. Test in a new Claude Code session.
Immediate payoff: every future session starts with full project context.
Exercise 0B Build Custom Slash Commands all projects ▶
  1. Create .claude/commands/code-review.md — "Review current file for bugs, performance, TS best practices."
  2. Create .claude/commands/fix-issue.md — "Fix issue #$ARGUMENTS following our coding standards."
  3. Create .claude/commands/deploy-check.md with disable-model-invocation: true
  4. Create global ~/.claude/commands/explain.md — works in every project
  5. Test each in a Claude Code session
Global commands in ~/.claude/commands/ work across all projects.
Exercise 0C Connect MCP Servers all projects ▶
  1. claude mcp add github -- npx -y @modelcontextprotocol/server-github
  2. Test: "list open issues in [your-repo]"
  3. Run /mcp to see connected servers and tools
  4. Advanced: build a custom MCP server for buffr's prompt library
Phase 3 prep: using MCP as a user prepares you to build MCP servers.
