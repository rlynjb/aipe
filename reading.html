Reading List

Ordered by phase · Free resources first · Links verified as of 2025–2026

These are the actual resources worth your time — curated for someone who learns by building, not by reading textbooks cover-to-cover. Everything free is marked. The paid resources are ones where there's no adequate free equivalent.

Phase 1–3 · LLM Engineering & Agents
GitHub · Free
LLM Course — Maxime Labonne
Maxime Labonne (Meta AI)
Two roadmaps: LLM Scientist (building models) and LLM Engineer (building products). Start with the Engineer track. Colab notebooks included. The best single free structured resource for your track.
Free · GitHub
Courses · Free
DeepLearning.AI Short Courses
Andrew Ng + OpenAI, Anthropic, LangChain
1–2 hour modules taught by the people who built the tools. Take: Prompt Engineering for Devs (OpenAI), Building with Claude (Anthropic), LangChain for LLM Development, Building Agentic RAG with LlamaIndex. Pick 5–6 and work through them in sequence.
Free
Docs · Free
Anthropic Prompt Engineering Guide
Anthropic
You're already using Claude Code daily — going deep on this pays off immediately. System prompts, tool use, context management, structured outputs, extended thinking. The most applicable doc you can read right now.
Free

Building Effective Agents
Anthropic Research
The most practical agentic architecture guide available. Covers orchestrator/subagent patterns, tool design, failure modes, and when NOT to use agents. Read this before building buffr's Phase 3 features. Short but dense.
Free
GitHub · Free
Anthropic Cookbook
Anthropic
Practical prompt patterns with working code. Structured output, tool use, multi-turn conversations, retrieval, embeddings. Start with the "tool_use" and "embeddings" sections — directly applicable to buffr.

LangChain
Language-agnostic concepts behind chains, agents, tools, memory, and retrievers. buffr implements most of these patterns manually — reading LangChain's terminology connects your code to industry vocabulary.
Free
Phase 4–5 · Production, RAG & Evals
Article · Free
Building LLM Apps (Production Patterns)
Chip Huyen
The canonical article on production LLM engineering. Cost, latency, fallbacks, evaluation, prompt versioning, streaming. Required reading before shipping any AI feature to users. Dense and practical.
Free
Reference · Free
Prompt Engineering Guide
DAIR.AI
Comprehensive reference covering every prompting pattern: zero-shot, few-shot, CoT, ReAct, RAG, and more. Language-agnostic. Works across Claude, GPT, Gemini, and open-source models. Use as a reference when a chain isn't behaving.
Free
Book · Paid
AI Engineering
Chip Huyen · O'Reilly 2024
From prototype to production. The most up-to-date book on the full AI product engineering stack: model selection, prompt engineering, RAG, fine-tuning, evaluation, deployment, monitoring. Buy this when you're in Phase 4–5. No free equivalent exists.
~$60 · O'Reilly
Book · Paid
LLM Engineer's Handbook
Paul Iusztin + Maxime Labonne · 2024
End-to-end: design → training data → fine-tuning → RAG → deployment → evaluation. The only book covering the full production LLM stack. Buy it when you reach Phase 4 and fine-tuning. Pairs perfectly with the free GitHub course above.
~$40 · Packt

Postgres + Auth + Realtime for JavaScript developers. The natural upgrade path from Netlify Blobs. Covers pgvector for semantic search, row-level security for auth, and SQL through a JS/TS lens. Read the pgvector section when you hit Phase 5 exercises.

Book · Paid
Designing Data-Intensive Applications
Martin Kleppmann · O'Reilly
The backend engineering bible. Storage, caching, replication, consistency, stream processing. You don't need to read it cover-to-cover — read chapters 1–3 (data models, storage engines) and chapter 7 (transactions/race conditions like TOCTOU). Long-term reference.
~$50 · O'Reilly
Papers worth knowing (read the abstract + conclusion, not necessarily everything)
Paper · Free
Attention Is All You Need
Vaswani et al · Google Brain 2017
The paper that introduced the transformer architecture powering every LLM you use. Read the abstract, the attention formula (Section 3.2), and Figure 2. Skip the machine translation results. Understanding this formula explains why context windows cost quadratically.
Free · arXiv
Paper · Free
Retrieval-Augmented Generation (RAG)
Lewis et al · Meta AI 2020
The original RAG paper. Short and readable. Explains the core concept of combining parametric knowledge (model weights) with non-parametric retrieval (vector search). Read when you're building Phase 5 exercises — it contextualises everything you're building.
Free · arXiv
Paper · Free
ReAct: Reasoning + Acting in LLMs
Yao et al · Princeton 2022
The paper behind buffr's suggestedActions pattern and the ReAct prompt engineering technique. Shows how interleaving reasoning and tool calls dramatically improves agent accuracy. Read it when building the observation loop exercise in Phase 3.
Free · arXiv
Paper · Free
LoRA: Low-Rank Adaptation
Hu et al · Microsoft 2021
The technique behind efficient fine-tuning of large models. Instead of updating all weights (expensive), LoRA adds small trainable matrices. Read the abstract and Section 2 — enough to understand what "LoRA fine-tuning" means when you see it in Hugging Face tutorials.
Free · arXiv
