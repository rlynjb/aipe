# AI-Era Software Engineer — Daily Debrief

> AI can generate code, but your value comes from understanding the problem, directing the implementation, evaluating the result, and defending the final design.
>
> Companion book: the [Field Playbook](../playbook/README.md), for use while the work is happening.

## How to use this book

Run this at the end of a work block or the end of the day — not as a to-do list, but as a reflection pass. Each chapter is its own file; open the one that matches today. Check what you can honestly say you did; let the blanks show where the day was thin.

- **Every day** — run the [Final Engineering Standard](12-final-engineering-standard.md) against whatever you shipped or touched. Ten honest checks. That is the core debrief.
- **When today felt shaky in one spot** — open the matching chapter and sit with its prompts.
- **Every week** — run the [Weekly Practice Loop](10-weekly-practice-loop.md).
- **When you're spread thin** — the [Priority Order](11-priority-order.md) says what to strengthen first.
